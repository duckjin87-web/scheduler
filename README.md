# 📅 스케줄러

업무용 캘린더 + 할 일(TODO)을 하나로 관리하는 **반응형 웹앱**입니다.
PC에서는 데스크탑 레이아웃, 스마트폰에서는 모바일 레이아웃으로 자동 전환되며,
정적 HTML/CSS/JS 한 파일로만 구성되어 별도 빌드 없이 브라우저에서 바로 열립니다.

데이터는 **브라우저(localStorage)에 저장**되어 새로고침해도 유지됩니다.

## 바로 쓰기

- 배포 주소: `https://duckjin87-web.github.io/scheduler/`
- 로컬에서: `index.html`을 브라우저로 열기만 하면 됩니다.

## 기능

**데스크탑 (PC)**
- 좌측 사이드바 네비게이션 (오늘 / 캘린더 / 할 일 / 설정)
- 실제 주간 캘린더 그리드 — 현재 주 기준, `‹ 오늘 ›`으로 주 이동, 빈 칸 클릭 시 해당 시간에 일정 추가
- 우측 대시보드 — 오늘 요약 KPI, 지연된 업무 + 이월 버튼, 중요 할 일

**모바일 (스마트폰)**
- 하단 5탭 네비게이션 + 우하단 `+` 빠른 추가(FAB)
- "오늘" 화면 우선 (오늘 일정 · 오늘 마감 · 지연된 할 일)
- 가로 스크롤 주간 캘린더

**공통**
- 일정 추가 / 수정 / 삭제 (제목 · 날짜 · 시간 · 장소 · 메모 · 분류)
- 할 일 추가 / 수정 / 삭제 / 완료 체크 (마감일 · 우선순위 긴급·높음·보통 · 분류)
- 업무 / 개인 분류 필터, 검색
- 지연된 할 일 **오늘로 이월**
- 다크 모드 (자동 + 수동 전환, 선택 저장)
- 설정 → 데이터 **백업 내보내기 / 가져오기(JSON)**, 전체 삭제

## 데이터 저장 & 동기화

- 현재 데이터는 **이 브라우저에만** 저장됩니다(localStorage). 다른 기기와 자동으로
  동기화되지 않습니다. 기기를 옮길 때는 설정 → 백업 내보내기/가져오기를 이용하세요.
- 코드의 데이터 계층(`Store`)은 나중에 백엔드로 교체하기 쉽게 분리되어 있어,
  다음 단계에서 기기 간 실시간 동기화를 붙일 수 있습니다.

## 로드맵

- [x] **1단계 — 데스크탑 기능** (주간 캘린더, 대시보드, 일정·할 일 CRUD)
- [x] **2단계 — 모바일 기능** (반응형, 하단 탭, FAB, 오늘 화면)
- [ ] **3단계 — 기기 간 동기화** (백엔드 연동: 로그인 + 실시간 동기화)
- [ ] 4단계 — 알림(Web Push), PWA 오프라인, 반복 일정, 통계

3단계는 서버(백엔드)가 필요합니다. GitHub Pages는 정적 호스팅이라, 예를 들어
Supabase(무료: 인증 + PostgreSQL + Realtime) 같은 서비스를 붙이는 방식으로 확장합니다.
